# Twister Booth

Tongue-twister diction training for interpreters and public speakers: English, French, German and ASL fingerspelling.

Play: https://vic-god.github.io/twister-booth/

Modes: 5-minute booth warm-up, speed run, repetition ladder, split attention, live rooms (everyone on their own device, joined with a 4-letter code, no account needed) and party mode on one device.
